# Life-session benchmark

Synthetic conversations between ordinary people and their personal AI agent, over six weeks, to measure two things a
personal agent's memory has to do for anyone:

1. **Know what is true now** about its person, at work and at home, through noise, changes of heart, corrections,
   plans only considered, what-ifs and other people's look-alike facts, and still know the history and the dates.
2. **Act on it:** when something said is a need someone could help with, look for a match on the network without
   being asked, and stop once the need is met.

How the set is built, and what counts as right, is in [RULES.md](RULES.md), written before any data was generated.

## The people

| Group | People | Use |
|---|---|---|
| test (`out/`) | 10: a nurse in Lyon, a teacher in Leeds, a restaurant owner in Valencia, a retired engineer in Kraków, an architecture student in Seoul, a photographer in Cape Town, a developer in Berlin, a vineyard owner near Mendoza, a lawyer on parental leave in Toronto, a founder in Bangalore | run once, after tuning ended |
| dev (`out_dev/`) | 2: a social worker in Seville, a bus driver in Hamburg | systems may be tuned on them |
| val (`out_val/`) | 2: a translator in Gothenburg, a pharmacist in Marseille | never tuned on: a change found on dev must not lose here |

Each person: 33 storylines (plain facts, changes, changes of heart, corrections, plans dropped or confirmed, what-ifs,
look-alikes, needs met, open or someone else's), about 50 sessions, about 46 questions.

## Files, per group

- `<person>/storylines.json`: the structure (from code and a seed) with the values; `truth.json`: what is true on
  every date, computed; `index.json`: the session plan; `sessions/NNN.jsonl`: the sessions, in Claude Code's format;
  `checks.json` and `judged.json`: every rejected draft and why.
- `questions.json`: questions with reference answers, from the truth; `questions_skipped.json`: storylines or
  questions not asked and why; `questions_review.json`: wording changes from the review.
- `network.json`: the people on the network and their circle/1 entries; `network_truth.json`: which entries would
  meet which need (planted matches and near misses).

## Running it

Needs: an OpenAI-compatible endpoint with two models from different families (here llama-swap at :9090, `daily` =
Qwen3.6-35B-A3B for writing and answering, `fast` = Gemma 4 26B for judging and grading), and for the Synalla arms
the embedder at :5941 (Qwen3-Embedding-0.6B).

```sh
# make a group (LIFE_SET=test|dev|val): storylines, sessions, judge rounds, network, questions
LIFE_SET=dev python -I -X utf8 network.py
bash gen.sh            # or gen2.sh: write -> judge -> rewrite, 4 rounds, then a final write
python -I -X utf8 judge.py && python -I -X utf8 questions.py   # the final write is judged too

# answer and grade (from the synalla-memory root)
node --import ./tools/ts-resolve.mjs benchmark/life-sessions/harness/synalla.mjs build [--variant v2]
node --import ./tools/ts-resolve.mjs benchmark/life-sessions/harness/synalla.mjs wants
node --import ./tools/ts-resolve.mjs benchmark/life-sessions/harness/synalla.mjs answer --arm A|D [--wants] --questions <q> --out <run>/answers_X.jsonl
python -I -X utf8 benchmark/life-sessions/harness/grade.py make <run> A D H O
python -I -X utf8 benchmark/life-sessions/harness/grade.py local <run> --model fast
python -I -X utf8 benchmark/life-sessions/harness/grade.py score <run> <run>/grades_local_fast.json
# proactive track
node --import ./tools/ts-resolve.mjs benchmark/life-sessions/harness/proactive.mjs --out <run>/proactive.jsonl
python -I -X utf8 benchmark/life-sessions/harness/score_proactive.py <run>/proactive.jsonl
```

`harness/hermes.py` and `harness/openclaw.py` run the same questions on Hermes Agent's and OpenClaw's built-in memory;
`runs/test_runs.sh` is the whole test chain. One GPU serves one model at a time: a job on the second model holds
`work/fast.lock`, and the jobs on the first wait (`gpu_lock.py`).

## Limits

The sessions are written by one model and judged by another; a contradiction both miss can remain. The questions are
generated by rules and were read by Claude, not yet by a person outside the project. Synthetic people are tidier than
real ones: one city each, needs stated plainly.
